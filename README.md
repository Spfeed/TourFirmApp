# ✈️ Информационная система для оформления заявок в туристической фирме

Веб-приложение для управления заявками в туристической фирме с чат-ботом на основе технологий машинного обучения. Разработано в рамках бакалаврской выпускной квалификационной работы (2024).

**[📄 English README below](#-english-version)**

---

## О проекте

Монолитное backend-приложение для автоматизации оформления заявок клиентов туристической фирмы, включая интеллектуального чат-бота для обработки типовых запросов.

## Ключевые характеристики

- Спроектирована архитектура системы (UML) и нормализованная модель базы данных
- Backend-приложение на Java/Spring Boot
- Чат-бот на основе ML-технологий (Python/FastAPI)
- Frontend на React/JavaScript
- Автоматизированные тесты для ключевых компонентов

## Технологический стек

| Категория | Технологии |
|---|---|
| Backend | Java, Spring Boot |
| Базы данных | PostgreSQL |
| ML/чат-бот | Python, FastAPI |
| Frontend | React, JavaScript |

## Запуск проекта

```bash
git clone https://github.com/Spfeed/TourFirmApp.git
cd TourFirmApp
```

Инструкции по запуску backend и frontend — в соответствующих директориях.

# Travel Agency Booking Management System

A web application for managing bookings at a travel agency, featuring an ML-based chatbot. Built as a Bachelor's thesis project (2024).

### Highlights

- Designed system architecture (UML) and a normalized database model
- Monolithic backend application on Java/Spring Boot
- ML-based chatbot (Python/FastAPI)
- Frontend on React/JavaScript
- Automated tests for key components

### Tech Stack

Java, Spring Boot, PostgreSQL, Python, FastAPI, React, JavaScript
